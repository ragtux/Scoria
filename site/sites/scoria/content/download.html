v0.3.2 · MIT · no installer, no account

Unpack it and point it at a vault.

Every release builds one archive per platform and a SHA256SUMS file over all of them, published on both forges. There is nothing to install and nothing to configure: the archive holds a single binary, and the binary takes the path to your vault.

Download for Linux What is in 0.3.2 Installing, in the manual

That address has no version in it and always resolves to the newest release; each release also carries the same archives named for their tag. GitHub carries all three platforms, and because the homelab Forgejo runner has only a Linux container, git.ragtux.com carries the Linux archive — the same build from the same tag.

Pick your platform

Linux is the platform Scoria is developed on, and the one that gets the hours. Since 0.3.1 the Windows and macOS builds are run on real hardware too, each drawing its own platform's window. They still see a fraction of the use Linux does, so if one of them misbehaves an issue is genuinely useful.

Running it

Scoria takes a vault as its argument. A vault is a folder of Markdown files — if Obsidian opens it, Scoria opens it, and it does not matter whether the folder has an .obsidian directory in it yet.

The manual's install page covers the command-line flags, and open a vault covers what happens on first launch.

From source

The repository builds with a stable toolchain pinned by rust-toolchain.toml. The one thing to know is that gpui is a git dependency pinned to a Zed release commit — the crates.io release is stale and crashes on NVIDIA — so build with --locked and let Cargo.lock decide.

Before you open a vault you care about

Scoria reads a vault well and writes one carefully, but writing is the newer half and this is v0.3.2. Two habits cost nothing and remove the whole risk:

  • Have a backup. A copy of the folder, or a git repository in it, or whatever you already use. This is good advice for any editor and better advice for a young one.
  • Try it on a scratch vault first. Copy a handful of notes into a new folder, edit them in Scoria, then open the folder in Obsidian and see that it looks like nothing happened. That is the same check Scoria's own round-trip gate makes.
