Releases

A v* tag builds the scoria binary on both forges and publishes one archive per platform with a SHA256SUMS file over all of them. Every release since 0.1.0 is listed here, newest first, and the three download addresses below always point at the newest one.

Linux x86-64 Windows x86-64 macOS Apple silicon Platform notes

Those addresses are versionless on purpose: they resolve to whatever the newest release is, so a link to them never goes stale. Each release also carries the same three archives named for their tag, which is what you want in a downloads folder you will come back to.

0.6.0 — the core plugins, nearly all of them

Released 11 November 2026. Phase 4 is parity with Obsidian's core plugins, and this release is most of its commands: 205 of the 244 command ids now run, each one probed against Obsidian 1.15.0 first and written to its bytes. The 39 left are services Scoria does not have, ids Obsidian does not register on desktop, and the window zoom and always on top, which wait on gpui.

Windows

Popouts, and tabs between them

A tab opens in a window of its own and comes back on the next launch where it was left; tabs drag between windows where the platform allows; the tab header has Obsidian's menu with pinned tabs; modals, the file menu and notices come up in the window they belong to; and a tab group stacks with workspace:toggle-stacked-tabs.

Page preview

Hover a link, read the note

The popover over links in the reading view and the editor, the tab header, the Files, Bookmarks, Backlinks, Outgoing links and Outline rows, bases and the graph — nested previews raised over each other, a clicked one an editor of its note, and a missing note created on click.

Editing

Vim keys and Slash commands

Vim key bindings behind vimMode; / at the start of a line or after a space offers the palette's commands, pinned and recent first; rename a heading and every link to it; add an alias; and the Format converter's frontmatter migration.

Core plugins

Composer, Workspaces and the rest

The Note composer's merge, split and extract; Workspaces' save and load in workspaces.json's bytes; the Unique note creator; Random note; the Footnotes view; backlinks at a note's foot; File properties; File recovery's snapshots, kept outside the vault and opened in a modal; and Slides and the graph timelapse.

Export and audio

PDF, PNG and an .m4a

A note exports to PDF with its blocks laid out and paginated, a canvas exports as an image, and the Audio recorder writes an AAC .m4a to the attachment folder and embeds it — all in pure Rust, in two new crates.

App

Commands, debug info, release notes

The app and window commands, the editor toggles, the file menu's path commands, the attachment commands named and placed as Obsidian names them, Show debug info, and these release notes inside the app. On macOS the hidden frame no longer drags the window off a tab press, and windows keep clear of the traffic lights.

Checking what you downloaded

Three independent checks, in increasing order of what they prove. None of them needs an account, and the first one is the one worth doing every time.

SHA256SUMS lists both names of every archive, so the check works whether you took the versionless address or the tagged one. On macOS the first command is shasum -a 256 -c --ignore-missing SHA256SUMS, and on Windows Get-FileHash prints a hash to compare by eye.

The signing key is 69BF AA44 7DAC E6C3 EF02 6CBA 4EA6 7A61 88DA 92BD (ragtux <ragtux@outlook.com>), which gpg --keyserver keys.openpgp.org --recv-keys 4EA67A6188DA92BD fetches; each release's notes repeat the fingerprint that signed it. A release published without the key available says so in its notes rather than carrying an unsigned .asc.

How a release is made

Two forges

The same tag, pushed twice

A v* tag on GitHub builds all three platforms; the same tag on git.ragtux.com builds the Linux archive, because the homelab runner has only a Linux container. Same commit, same Cargo.lock, same binary.

Gate

The tag has to match the manifest

The first job compares the tag against the workspace version and fails the release before a build slot is spent if they disagree — the archives are named from the tag and the binary reports the manifest, so a mismatch would ship a lie.

Reproducible

Built --locked

Cargo.lock pins libc and the exact GPUI revision on purpose, and the release job builds with --locked so the lockfile decides. Building the tag yourself gives you the same dependency graph CI used.
