Releases

A v* tag builds the scoria binary on both forges and publishes one archive per platform with a SHA256SUMS file over all of them. Every release since 0.1.0 is listed here, newest first, and the three download addresses below always point at the newest one.

Linux x86-64 Windows x86-64 macOS Apple silicon Platform notes

Those addresses are versionless on purpose: they resolve to whatever the newest release is, so a link to them never goes stale. Each release also carries the same three archives named for their tag, which is what you want in a downloads folder you will come back to.

0.7.0 — the corners of the core plugins

Released 16 November 2026. Every row of phase 4's table is now done: 210 of the 244 command ids run, and the 34 left are services Scoria does not have and ids Obsidian does not register on desktop. As before, each piece was watched in Obsidian 1.15 first and written to what it did.

Rendering

Mermaid, and the HTML that was missing

Mermaid diagrams are laid out as Obsidian's own Pele lays them out, through a Rust port, and painted in the reading view, Live Preview, embeds, previews and PDF export. Superscript, subscript and small HTML tags draw at their size and baseline, an inline style's colours and weights apply, and a raw table keeps its colspan, rowspan and caption.

Files

PDFs, canvases, audio

A PDF's text selects and copies, with #selection= links, two-page spreads, Adapt to theme and the password prompt. An embedded canvas is its minimap, as Obsidian draws it. Audio plays in a tab and embedded; a video is a card that opens in the default app.

Editing

Spelling, pasting, line numbers

Spellcheck on Hunspell dictionaries, with corrections and Add to dictionary in the editor menu. Copied HTML pastes as Markdown, and images and files from the clipboard or a file manager are saved as attachments. Line numbers, indentation guides and right-to-left text.

Panes and bases

Ranges of cells, an editable File properties

A base's table selects ranges of cells with Shift and Ctrl+A, copies them as tab-separated text, pastes over them and empties them. The File properties pane edits, closes and previews, in every view. Search results have their right-click menus.

Settings

Excluded files, and rows that act

Excluded files are matched as Obsidian matches them, hidden from search, the graph, unlinked mentions, tags and bases, ranked last in the switcher and autocompletion, and edited on their own Settings page. Show tab title bar and Always focus new tabs take effect, File recovery's View and Clear work, and template rows pick a file.

Window and app

Zoom, always on top, reload

The window zooms with Ctrl+=, Ctrl+- and Ctrl+0, stays on top where the platform lets it, and Reload app without saving reads the vault and its configuration again. Ctrl+Enter in an extraction prompt makes a new note. And the plugin runtime for phase 5 is chosen: WebAssembly components on wasmtime, measured on Linux and Windows.

Checking what you downloaded

Three independent checks, in increasing order of what they prove. None of them needs an account, and the first one is the one worth doing every time.

SHA256SUMS lists both names of every archive, so the check works whether you took the versionless address or the tagged one. On macOS the first command is shasum -a 256 -c --ignore-missing SHA256SUMS, and on Windows Get-FileHash prints a hash to compare by eye.

The signing key is 69BF AA44 7DAC E6C3 EF02 6CBA 4EA6 7A61 88DA 92BD (ragtux <ragtux@outlook.com>), which gpg --keyserver keys.openpgp.org --recv-keys 4EA67A6188DA92BD fetches; each release's notes repeat the fingerprint that signed it. A release published without the key available says so in its notes rather than carrying an unsigned .asc.

How a release is made

Two forges

The same tag, pushed twice

A v* tag on GitHub builds all three platforms; the same tag on git.ragtux.com builds the Linux archive, because the homelab runner has only a Linux container. Same commit, same Cargo.lock, same binary.

Gate

The tag has to match the manifest

The first job compares the tag against the workspace version and fails the release before a build slot is spent if they disagree — the archives are named from the tag and the binary reports the manifest, so a mismatch would ship a lie.

Reproducible

Built --locked

Cargo.lock pins libc and the exact GPUI revision on purpose, and the release job builds with --locked so the lockfile decides. Building the tag yourself gives you the same dependency graph CI used.
